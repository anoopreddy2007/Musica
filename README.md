# Musica

Musica is a simple personal music streaming web application.

## Current Features

- YouTube Music search
- Song metadata and thumbnails
- Audio playback
- Play / Pause
- Previous / Next
- Shuffle
- Repeat
- Seek controls
- Volume control
- Queue management
- Queue drag and drop

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Python
- FastAPI
- ytmusicapi
- yt-dlp
